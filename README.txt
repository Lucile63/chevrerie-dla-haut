LA CHÈVRERIE D'LÀ-HAUT — SITE VITRINE
======================================

OUVRIR LE SITE
--------------
Double-cliquer sur index.html pour voir le site dans un navigateur.
Pour une prévisualisation complète du lecteur vidéo et des liens, utiliser un petit serveur local ou publier le dossier sur un hébergement web.

MISE EN LIGNE
-------------
Téléverser l'intégralité du dossier sur l'hébergement, en conservant exactement cette structure :
- index.html
- mentions-legales.html
- assets/

Le fichier index.html doit rester à la racine du domaine.

AVANT PUBLICATION
-----------------
1. Compléter le numéro SIRET dans mentions-legales.html.
2. Compléter les coordonnées de l'hébergeur dans mentions-legales.html.
3. Faire valider par Jérôme la gamme de produits encore commercialisée et les poids indicatifs.
4. Vérifier la formulation de la zone de livraison.
5. Remplacer ou compléter les photographies lorsque de nouveaux visuels seront disponibles.

MODIFIER UN TEXTE
-----------------
Ouvrir index.html dans un éditeur de texte ou de code, rechercher le texte à modifier, enregistrer puis remettre le fichier en ligne.

MODIFIER UNE PHOTO
------------------
Remplacer le fichier correspondant dans assets/images/ en conservant le même nom et, si possible, un format horizontal 4:3 pour les produits.

FORMULAIRE
----------
Le formulaire n'envoie aucune donnée à un serveur. Il prépare un e-mail dans la messagerie du visiteur. Aucun abonnement ou service tiers n'est nécessaire.
